# ADR-0001 — Start with Inception Before Coding

## Status

Accepted

## Date

2026-07-01

## Context

KUNNA started as a UX/UI prototype created several years ago. The current goal is not to recreate the visual interface immediately, but to rebuild the project as evidence of professional software engineering practice.

The project will follow an iterative approach inspired by use-case driven development, UML modeling, object-oriented analysis, GRASP principles, and progressive Java implementation.

## Decision

The project will start with an Inception Package before writing production code.

The first milestone will be:

**I1 — Inception Package**

This milestone includes:

- Repository structure.
- Initial README.
- Project vision.
- User goals.
- Use case model.
- Supplementary specification.
- Glossary.
- Risk list.
- Development plan.
- Development framework.
- AI collaboration policy.
- Decision journal.
- Initial product backlog.

## Consequences

### Positive

- The project will show professional reasoning before implementation.
- The repository will provide evidence of analysis, design, and decision-making.
- The project will be aligned with software engineering learning goals.
- Code will be easier to justify because it will come from documented requirements and design artifacts.

### Negative

- The project will progress more slowly at the beginning.
- There will be less visible code in the first phase.
- Discipline is required to avoid jumping directly into implementation.

## Rule

No production code will be added until the Inception Package has enough clarity to justify the first implementation iteration.
