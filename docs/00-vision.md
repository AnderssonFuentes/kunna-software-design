# 00 — Project Vision

## Product Name

KUNNA

## Vision Statement

KUNNA is a digital product designed to support mothers, fathers, and caregivers with accessible content about children's rights, positive parenting, and daily care practices.

The software engineering goal of this project is to rebuild an original UX/UI prototype as a documented, iterative, object-oriented software project.

## Problem

Caregivers often need clear, practical, and trustworthy guidance about children's rights and positive parenting. However, this information can be fragmented, difficult to understand, or disconnected from daily caregiving situations.

## Target Users

- Mothers.
- Fathers.
- Caregivers.
- People responsible for the daily care and protection of children.

## Expected Outcome

The project should demonstrate the ability to transform a UX/UI prototype into a software engineering project through:

- Product reasoning.
- User goal analysis.
- Use cases.
- Requirements.
- UML modeling.
- Domain modeling.
- Object-oriented design.
- Documented decisions.
- Progressive Java implementation.

## Scope of the Inception Phase

The Inception phase does not aim to build the final application. Its goal is to clarify the product direction, identify users, define initial use cases, document risks, and establish a professional development framework.

## Out of Scope for Now

- Production code.
- Spring Boot API.
- Database design.
- Authentication implementation.
- Mobile application development.
- Final UI implementation.
